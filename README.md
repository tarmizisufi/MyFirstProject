# CSC649 Setup Lab - Sentence Analyzer

A simple Python command-line utility to analyze text input by computing word count and character counts.

---

## Features
- Accurately counts words even when input contains erratic or consecutive whitespace.
- Computes character count both with and without whitespace.
- Validates input and alerts the user if empty input is provided.

---

## Requirements
- Python 3.12.x
- Git
